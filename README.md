# 🅿️ 3D Симулатор за паркиране

Браузърна 3D игра-симулатор за паркиране, оптимизирана за **iPad с touch управление**.
Графиката е на **Three.js**, физиката на **cannon-es**, заредени директно през CDN —
**няма build процес**. Достатъчно е да отвориш `index.html` (през уеб сървър / GitHub Pages).

## ▶ Как се играе

- **Отляво** — бутони за волана: **⟲ наляво** и **⟳ надясно**.
- **Отдясно** — педали: **▲ газ напред** и **▼ спирачка / заден ход**.
- Бутоните са големи и полупрозрачни, реагират на **задържане** (мулти-тъч).
- Воланът работи **по-малко при висока скорост** — карай плавно.
- 📷 сменя изгледа (**зад колата ↔ отгоре**) за по-лесно паркиране.
- 🔊 включва/изключва звука, ↺ рестартира нивото.
- Помощните линии зад колата се **извиват според волана** (като камера за заден ход).
- Цел: вкарай колата **изцяло** в зеленото място, под правилен ъгъл, и **спри**.
- Не удряй колите, стълбовете и конусите — щетите свалят точки!

> На десктоп може да се играе и с клавиатура: стрелки / WASD, `C` за камера, `R` за рестарт.

## 🎮 Нива

1. **Прав вход** — просто паркиране напред.
2. **Заден ход** — влизане на заден ход.
3. **Паралелно паркиране** — между две коли край бордюра.
4. **Тясно място** — претъпкан паркинг с коли, стълбове и конуси.

Точките зависят от **времето** и **щетите** — по-бързо и без удари = повече точки.

## 🚀 Пускане

### GitHub Pages
1. Качи файловете в хранилището (вече са в този branch).
2. Settings → Pages → Source: branch с тези файлове, папка `/ (root)`.
3. Отвори публикувания адрес — играта тръгва веднага.

### Локално
Понеже се ползват ES модули, отвори през локален сървър (не `file://`):
```bash
python3 -m http.server 8000
# после: http://localhost:8000
```

## 🗂 Структура

```
index.html          # разметка, HUD, touch бутони, importmap (CDN)
css/style.css       # стилове и touch UI
js/
  main.js           # оркестрация, игрови цикъл, нива, камера
  physics.js        # cannon-es свят и материали
  car.js            # физика на колата (RaycastVehicle) + 3D модел
  environment.js    # осветление, земя, град, място, препятствия
  levels.js         # дефиниции на нивата
  controls.js       # touch + клавиатурно управление
  hud.js            # HUD и съобщения
  audio.js          # звуци (WebAudio)
  guidelines.js     # помощни линии за паркиране
  parking.js        # проверка за успешно паркиране и точки
```

## 🛠 Технологии
- [Three.js](https://threejs.org/) `0.160.0` — рендиране, сенки, осветление
- [cannon-es](https://github.com/pmndrs/cannon-es) `0.20.0` — физика, `RaycastVehicle`
- Зареждане през `importmap` от CDN (unpkg), без bundler.
